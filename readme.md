# 📦 Elite Globex ERP

A complete ERP (Enterprise Resource Planning) system developed using **Node.js, Express.js, MySQL, EJS, and Bootstrap**.

---

## 🚀 Features

### 🔐 Authentication
- Login
- Logout
- Session Management

### 👥 Customer Management
- Add Customer
- Edit Customer
- Delete Customer
- Search Customer

### 📦 Product Management
- Add Product
- Edit Product
- Delete Product

### 📋 Order Management
- Create Order
- View Order
- Edit Order
- Delete Order
- Multiple Product Support
- Auto Price Calculation
- Auto Total Calculation
- Payment Status
- Delivery Status

### 📊 Dashboard
- Total Customers
- Total Products
- Total Orders
- Quick Navigation

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MySQL
- EJS
- Bootstrap 5
- JavaScript
